# What is DevOps?
## DevOps Summary
DevOps is a set of practices that combines **Development (Dev)** and **Operations (Ops)** to improve collaboration and automate software delivery.

Its goal is to build, test, and release software faster, more reliably, and with fewer errors through practices such as **Continuous Integration (CI)** and **Continuous Delivery/Deployment (CI/CD)**, ultimately delivering greater value to customers.

## View
DevOps considers everyone involved in the software delivery process, including:

- Security teams
- Infrastructure engineers
- Developers
- Stakeholders
- Cloud architects

It focuses on how systems should be designed and operated so that automation makes work easier for everyone involved.

## Philosophy
DevOps is built around:

- Customer focus
- Continuous improvement
- Delivering value quickly
- Reliable software delivery

## Culture
DevOps promotes:

- Collaboration
- Shared responsibility
- Communication
- Trust
- Breaking down silos between teams

## Set of Practices
DevOps aims to shorten the software development lifecycle through:

- Continuous Integration (CI)
- Continuous Delivery/Deployment (CD)
- Infrastructure as Code (IaC)
- Automation
- Monitoring
- Testing
- Feedback loops
